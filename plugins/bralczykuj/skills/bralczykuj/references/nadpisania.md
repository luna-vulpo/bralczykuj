# Nadpisania — reguły użytkownika nad Miodkujem

Ten plik ma pierwszeństwo przed każdym innym plikiem w `references/`. Reguły ustalone
27–28.10.2026 przy przeglądzie tekstów aplikacji Piąta Żyła; obowiązują w każdym polskim
tekście, który da się podzielić na polecenia i opisy.

## Sprzeczności z Miodkujem i ich rozstrzygnięcie

| Miodkuj (`plain-polish.md`) | Bralczykuj |
| --- | --- |
| „Address the reader directly when appropriate.” | Wprost tylko w poleceniu (tryb rozkazujący). Opis bez drugiej osoby. |
| „Signals to reduce: passive constructions, impersonal forms.” | W opisie strona bierna i „należy” **mają pierwszeństwo** przed formą z „się”. Ograniczać wolno wyłącznie łańcuchy ciężkie („zostaje dokonane”, „jest realizowane”). |
| `niniejszy` → `ten` | `niniejszy` → usunąć albo nazwać rzecz wprost; zaimka nie wstawiać (reguła 8). |
| `w dniu dzisiejszym` → `dzisiaj` | Najpierw sprawdzić, czy „dzisiaj” wnosi treść; jeśli nie — usunąć (reguła 12). |

## Reguły z przykładami

### 1–2. Polecenie: rozkaźnik, czasownik na początku

| Źle | Dobrze |
| --- | --- |
| Nazwę wpisuje się bez skrótu rodzaju. | Wpisz nazwę bez skrótu rodzaju. |
| Numer budynku przepisz z tabliczki. | Przepisz numer budynku z tabliczki. |
| Jeśli w rozdzielnicy jest inny aparat, wskaż go. | Wskaż aparat z rozdzielnicy, jeśli jest inny. |

Polecenie to zdanie mówiące czytelnikowi, co ma zrobić w aplikacji albo na obiekcie. Forma
przyszła („Uzupełnisz go w…”, „Wskażesz…”) też jest poleceniem — zamienia się ją na rozkaźnik.

### 3. Opis: bierna albo „należy”

| Źle | Dobrze |
| --- | --- |
| Parametry potwierdza się po obejrzeniu. | Parametry należy potwierdzić po obejrzeniu. |
| Oficynę wprowadza się jako klatkę. | Oficynę należy wpisać jako klatkę. / Oficyna jest wpisywana jako klatka. |
| Orzeczenie jest Twoje. | Orzeczenie wydaje wykonujący. |

Obowiązek osoby trzeciej (np. zarządcy) opisuje się bierną albo „należy”, nie rozkaźnikiem.

### 4. Dokument nie jest podmiotem czynności

| Źle | Dobrze |
| --- | --- |
| Protokół to odnotuje. | W protokole zostanie to odnotowane. |
| Protokół nie mówi, czy… | Protokół nie zawiera informacji, czy… |
| Dokument będzie o nim milczał. | W dokumencie nie zostanie o nim nic umieszczone. |
| Protokół poda je jako niezmierzone. | W protokole zostaną podane jako niezmierzone. |

### 5. Bez „nikt”

| Źle | Dobrze |
| --- | --- |
| Nikt go nie potwierdził. | Nie został potwierdzony. |
| …znaczy, że nikt ich nie sprawdził. | …znaczy, że nie zostały sprawdzone. |

### 6. Bez „po cichu”

| Źle | Dobrze |
| --- | --- |
| Pominięty pomiar nie przechodzi po cichu. | Pominięty pomiar zostaje wykazany jako brak. |
| …nigdy jako cichy sukces. | …nigdy jako wynik pozytywny. (tylko gdy źródło to mówi) |

### 7. Bez „stoi / stanie” w znaczeniu położenia

| Źle | Dobrze |
| --- | --- |
| Element stoi na pulpicie jako niedokończony. | Element widnieje na pulpicie jako niedokończony. |
| W protokole stanie „nie ustalono”. | W protokole zostanie wpisane „nie ustalono”. |
| Czas stoi w tablicy normy wyrobu. | Czas podaje tablica normy wyrobu. |

Znaczenia dosłowne i stałe zostają: „prąd stały”, „w jakim stanie”, „co się stanie”.

### 8. Zaimki wskazujące

| Źle | Dobrze |
| --- | --- |
| Pomiar w tej kontroli | Pomiar w kontroli |
| Wskaż go na tym ekranie. | Wskaż go na ekranie. |
| Ten obwód nie ma RCD. | Obwód nie ma RCD. |

Zaimek zostaje, gdy odróżnia: „w kontroli tej, a nie poprzedniej”, „W tym układzie
(w odróżnieniu od TN)…”.

### 9. „Być” → równoważnik albo inny czasownik

| Źle | Dobrze |
| --- | --- |
| Bez wskazania będzie w nim wpisane „nie wskazano”. | Brak wskazania daje wpis „nie wskazano”. |
| Pole jest nieobowiązkowe. | Pole nieobowiązkowe. |
| Wykaz mierników jest pusty. | Wykaz mierników pusty. / Brak mierników w wykazie. |

„Być” zostaje, gdy zamiana psuje sens albo brzmi sztucznie.

### 10. Zdanie podrzędne → fraza

| Źle | Dobrze |
| --- | --- |
| mierniki, którymi wykonano tę kontrolę | mierniki użyte do wykonania kontroli |
| obwody, które mają wyłącznik różnicowoprądowy | obwody z wyłącznikiem różnicowoprądowym |

### 11. Bez „Zrób raz … dla …”

| Źle | Dobrze |
| --- | --- |
| Wskażesz go raz, dla całej kontroli, nad listą elementów. | Stan gruntu wskazany nad listą elementów obowiązuje całą kontrolę. |
| Próby wyłącznika wpisuje się raz — wynik obowiązuje każdy obwód. | Wynik próby wyłącznika obowiązuje każdy obwód za nim. |

### 12. Bez redundancji

| Źle | Dobrze |
| --- | --- |
| …po obejrzeniu tego, co jest w budynku dzisiaj. | …po obejrzeniu instalacji. |
| Za każdym razem, gdy… | Gdy… |
| To nie jest wcale formalność. | (usunąć albo podać, czemu służy — ze źródła) |

### 13. Okolicznik zaraz po czasowniku

| Źle | Dobrze |
| --- | --- |
| Zapisz wynik od razu. | Zapisz od razu wynik. |
| Uzupełnij dane wykonującego potem. | Uzupełnij potem dane wykonującego. |
| Wskaż aparat nadrzędny ponownie przy obwodzie. | Wskaż ponownie aparat nadrzędny przy obwodzie. |

Reguła przesuwa **wyłącznie okolicznik** — przed dopełnienie, zaraz za czasownik. Nie zmienia
szyku podmiot–orzeczenie: „Poprzednie kontrole zostają bez zmian” jest poprawne, gdy po
czasowniku stoi już tylko okolicznik; „Zostają bez zmian poprzednie kontrole” to inwersja,
nie poprawka. Okolicznik zostaje na końcu także wtedy, gdy przestawienie zmienia sens albo
rozbija frazę stałą.

## Lista kontrolna (po każdej edycji, obok `eval.md`)

- Czy każde polecenie ma rozkaźnik i zaczyna się od czasownika?
- Czy opisy są bez drugiej osoby i bez formy z „się” tam, gdzie „należy” albo bierna
  brzmią naturalnie?
- Czy żaden dokument, ekran ani plik nie „mówi”, „podaje”, „odnotowuje”, „milczy”?
- Czy w tekście nie ma „nikt”, „po cichu”, „cichy”, „stoi/stanie” w znaczeniu położenia?
- Czy każdy zaimek wskazujący coś odróżnia?
- Czy zdania z „być” dało się zamienić — i czy zamiana nie zepsuła sensu?
- Czy zdania podrzędne, które dało się skrócić do frazy, zostały skrócone?
- Czy nie ma „raz, dla”, „dzisiaj” bez treści i powtórzeń tej samej myśli?
- Czy „bez zmian”, „od razu”, „potem” i podobne stoją zaraz po czasowniku, przed
  dopełnieniem — i czy przy tym nie przestawiono podmiotu za orzeczenie?
- Czy fakty, liczby, przywołania, nazwy pól i wstawki `$…` zostały dosłownie?
